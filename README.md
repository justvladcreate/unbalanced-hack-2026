# unbalanced-hack-2026

Прототип системы «Умный дом» для хакатона **UNBALANCED 2026**. Проект закрывает кейс по автоматизации многоквартирного дома на основе устройств платформы **Ujin**: жильцы и управляющая компания управляют датчиками, счётчиками, шлагбаумами, лифтами и другими устройствами через веб-интерфейс.

---

## О проекте

Решение состоит из трёх частей:

- **Фронтенд** — веб-интерфейс на чистом HTML/JS: вход по ролям (админ / жилец / жилец с правами), список устройств, сценарии автоматизации, уведомления, заявки на права.
- **Бэкенд** — API сервера на **Express** (Node.js) для фронтенда + справочник устройств на **FastAPI**.
- **Эмуляторы** — Python-модели устройств: датчик протечки, шлагбаум, термостат, лифт, счётчик, свет, вентиляция, ПОЖС и др., которые публикуют сигналы и принимают команды платформы.

---

## Как работает

1. **Вход и роли.** Пользователь регистрируется или входит (`/api/login`). Есть три уровня доступа:
   - **Админ** — управляет устройствами, сценариями и заявками жильцов.
   - **Жилец** — только просматривает устройства и запрашивает права.

2. **Устройства.** Управляющая компания добавляет устройства. Список отображается жильцам. Статусы устройств периодически синхронизируются с платформой Ujin (в Express-прототипе — имитация через интервал).

3. **Сценарии.** Логика автоматизации («если протечка — выключить воду») создаётся админом, может быть общей (общей для всех) или личной.

4. **Заявки на права.** Жилец отправляет запрос (`/api/requests`), админ одобряет или отклоняет его; после одобрения у жильца появляется доступ к управлению.

5. **Уведомления.** Плановые и аварийные сообщения отображаются в ленте (`/api/notifications`).

## Запуск

### Бэкенд для фронтенда (Express)

```bash
cd backend_2
npm install
node index.js        # http://localhost:3000
```

### Справочник устройств (FastAPI)

```bash
pip install -r backend\requirements.txt    # или backend_2\requirements.txt
python -m uvicorn main:app --reload        # из корня проекта
# Swagger: http://127.0.0.1:8000/docs
```

### Эмуляторы

Быстрый старт:

```bash
python main.py elevator --ticks 8 --interval 0 --floors 5
```

Тесты эмуляторов (офлайн):

```bash
python -m unittest discover -s tests   # из папки emulators
```
