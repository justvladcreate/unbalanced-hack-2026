## *Что это?*
Unbalanced Smart Home это веб платформа для проектирования и проверки сценариев умного дома на базе Ujin OS. Она объединяет конструктор устройств, эмуляторы оборудования, редактор сценариев и интерфейс для жильца и администратора УК. Пользователь добавляет устройство, выбирает тип из семейств Ujin, указывает единицу измерения, смотрит декларацию возможностей, создаёт сценарий с условием и действием, проверяет его на эмуляторе и получает уведомление.

## Как это работает?
Проект работает на FastAPI, PostgreSQL, SQLAlchemy, Alembic и Node.js с Express. Node раздаёт интерфейс и запускает FastAPI, а FastAPI отвечает за авторизацию, устройства, сценарии и интеграцию с Ujin. Поддерживается вход по локальной учётной записи и по реальному телефону и паролю Ujin. Для безопасной демонстрации команды устройствам выполняются в режиме dry run.

В проекте есть роли администратора и жильца, заявки на доступ, скрытие устройств без разрешения УК, добавление, изменение и удаление устройств, девять семейств эмуляторов, график сигналов, управление устройством, создание, изменение и удаление сценариев, обработка недоступных устройств и демонстрационный сценарий протечки с закрытием клапана и уведомлением. Прототип запускается локально и показывает полный цикл от входа до выполнения автоматизации без реального оборудования.
